# Authorization

RentAI API provides authorization endpoints for working with user accounts.

## How to authenticate

1. Open the API Reference.
2. Find the authorization endpoints.
3. Register or sign in using the request schema specified by the API.
4. If the API returns an access token, use it as required by the protected endpoints.

The exact request fields, token format, and authorization requirements are defined in the OpenAPI specification.

## Security

Do not share access tokens or store secrets in public repositories.
