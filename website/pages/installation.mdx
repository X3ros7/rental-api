# Installation

RentAI API — REST API для системы аренды жилья.

## Requirements

- Python 3.10+
- pip
- Git

## Run the project

1. Clone the repository.
2. Install the dependencies.
3. Configure the environment variables using `.env.example`.
4. Start the FastAPI application.

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

After startup, the API is available at `http://127.0.0.1:8000`.

Interactive API documentation is available at `/docs`, and the OpenAPI schema at `/openapi.json`.

## Python SDK

The generated Python SDK is located in the `sdk` directory of the project.
